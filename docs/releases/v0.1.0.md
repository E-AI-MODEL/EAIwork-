# EAI work v0.1.0

First public release of the evidence-first EAI workbench.

## Included

- atomic work packs with dependencies and rule-based review signals
- derived evidence ladder: `unknown → assumption → claim → observed → checked → proven`
- model asymmetry: models may propose, flag and lower confidence, but cannot raise status
- evidence inspector, work graph, status distributions and review queue
- append-only event and rejection logs with hash chaining
- Ed25519-signed, cryptographically chained witness journals outside the datastore
- default-deny per-atom read/write/check/audit authorization
- server-controlled evidence lineage and server-only deterministic checks
- scoped deterministic-check inputs to prevent hidden-state oracle behavior
- request-size and rate limits, CSP/security headers and explicit strong-token configuration
- fail-closed log verification, exclusive writer locking and restricted datastore permissions
- cached constant-time integrity verification on the request path
- regression coverage for 5,000 rejected writes without repeated full witness scans
- conformance vectors covering the main status-escalation and evidence-forging paths

## Runtime

- Node.js 22.18 or newer
- no runtime npm dependencies
- server binds to `127.0.0.1` by default
- explicit token configuration and external witness configuration are required

## Migration note

Existing non-empty datastores must be locally verified and explicitly bootstrapped into the witness system before first start with this release. See the README for `verify-local`, `bootstrap-witness` and `verify-log`.

## Security

The release includes the fixes from the repository pentest and follow-up security reviews, including protection against forged evidence lineage, public `check.passed` injection, model downgrade attacks, log rollback, witness tampering, rejection-log DoS growth and datastore write races.
